A journal that can stay open

An editable interface prototype based on your e-journal.

Add an occasion, not a level

Use Add experience column for another subject, task or context. Each competency has its own journal. Use the competency links to move between them; your entries stay with the competency you selected. Critical Thinking contains examples. The other templates include the annex indicators and questions, with blank spaces for demonstrations and reflections. Each entry has its own subject and date, including entries under CAIT 2. Click an entry's pencil to edit these details, its reflection, evidence or later review. A dated review appears alongside the earlier reflection.

Let dialogue change an interpretation

Switch to Teacher view, then click Add feedback or a feedback button on any entry. Switch to Student view to add a response. This is a view switch for demonstrating the interface, not separate user accounts.

Keep the indicators revisable

Use Propose indicator row to add your own wording and questions. Use the pencil beside an existing indicator to revise its wording. A new proposal is a starting point for discussion, not an automatic new criterion.

Save and edit

Changes save in this browser on this device. Export a JSON backup to keep a transferable copy, or download a self-contained HTML version. The SVG export contains editable vector shapes and text for use in a graphics editor.

About this prototype

The initial entries and dialogue are fictional examples adapted from your workbook. This prototype does not synchronise across devices or authenticate teachers. You can attach photos, videos and audio, or add an evidence link or reference. Attachments stay in this browser; JSON backups and interactive HTML copies include the attached files. It has no scores, levels or completion requirements.

CAIT 1 and CAIT 2 wording and reflection questions supplied by the user. Critical Thinking draws on MOE's Learning Goals and Developmental Milestones for Emerging 21CC (2023), pp. 13 and 16.
